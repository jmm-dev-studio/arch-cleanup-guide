# Blog article sample

Practical Linux/Arch tutorial in two languages, by JMM Dev Studio:

- `arch-cleanup-en.md` (English)
- `arch-aufraeumen-de.md` (Deutsch)

Topic: a safe monthly cleanup routine for pacman cache, orphaned packages, systemd journal and AUR caches.
Each version is about 800 words and was written natively in its language, not machine-translated line by line.
Flags and units (paccache -d/-r/-k/-u, paccache.timer, journalctl --vacuum-*, pacman -D --asexplicit) were checked against the installed tools (paccache 1.13.1) on an Arch system.
